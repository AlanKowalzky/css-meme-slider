## 📝 About the Project
This project is an interactive meme slider built as part of the Rolling Scopes School curriculum. 

The application strictly adheres to the rule of **zero JavaScript usage**. All components—including slide switching, dynamic text captions, navigation dot state management, and active state persistence—are controlled purely through native HTML5 and CSS3 (`:checked` pseudo-classes and sibling selectors `~`). 

Additionally, the layout entirely avoids absolute positioning (`position: absolute`), ensuring all elements remain within the natural document flow using CSS Grid overlay techniques.

---

## 🛠️ Tech Stack & Key Features
- **HTML5:** Semantic architecture with validated syntax.
- **CSS3:** Advanced Flexbox layouts, CSS Grid overlays, and custom properties (variables).
- **Pure CSS Logic:** Interactivity is entirely state-driven without scripting.
- **Responsive & Fluid:** The slider smoothly shifts heights dynamically to preserve native image aspect ratios while keeping navigation elements cleanly aligned.
